## Content Templates

### Blog Structure (800-1500 words)
```
H1: Compelling headline with keyword
Hook: Problem statement (2-3 sentences)
H2: What is [topic]?
Body: Explanation with examples
H2: Why it matters for Africa
Body: Local context, stats
H2: How RPNMore solves this
Body: Service features, benefits
H2: Case study / Real example
Body: Results, testimonials
CTA: Book consultation / See pricing
Related posts: 3 internal links
```

### LinkedIn Post Structure
```
Hook: Personal story or bold claim (2-3 lines)

Context: Why this matters (2-3 lines)

Link: Blog URL with preview

CTA: "Read the full guide →"

Hashtags: 3-5 relevant
```

### X Thread Structure
```
Tweet 1: Hook + link to blog
Tweet 2-5: Key insights from blog
Tweet 6: CTA + link again
```
